# Glossary

- Actor - external participant of product behavior, for example operator, administrator, root user.
- Architecture Snapshot - canonical JSON file used by documentation and Architecture Hub.
- Business Process - ordered sequence of domain actions and facts.
- Business Rule - invariant or calculation that must stay true in code.
- Component - runtime/build unit: frontend, backend, database.
- Confidence - trust level of a fact: high, medium, low.
- Data Table - physical SQLite table.
- Entity - domain object used by business logic.
- Evidence - source explaining why a fact exists in the snapshot.
- Interaction - sequence-ready message list between participants.
- Model Contract - minimum data needed to render a future diagram/model correctly.
- Module - product/technical area with entities, services and API.
- Permission - atomic access right.
- Role - RBAC grouping of permissions.
- Source of Truth - owner of a concept or calculation.
- State - lifecycle value of an entity.
- Transition - allowed change between states.
- Use Case - user goal independent from implementation endpoint names.
